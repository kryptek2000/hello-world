## 🕰️ A Brief History of "Hello, World"

Every programmer's first words have a paper trail — and it starts at Bell Labs.

**Early 1970s — the B language.**
The earliest known appearance of the phrase is in documentation for **B**,
the ancestor of C. Small test programs existed before, but this is where
"hello, world" first shows up in print.

**1974 — the Bell Labs memo.**
[Brian Kernighan](https://en.wikipedia.org/wiki/Brian_Kernighan) writes
*Programming in C: A Tutorial*, an internal Bell Laboratories memorandum.
Its example program prints the words that would conquer computing:

```c
main( ) {
        printf("hello, world");
}
```

No newline. No capital letter. No exclamation mark. The humblest
masterpiece in software history.

**1978 — K&R makes it immortal.**
Kernighan and [Dennis Ritchie](https://en.wikipedia.org/wiki/Dennis_Ritchie)
publish *The C Programming Language* (Prentice Hall, 1st ed.). The example
reappears on page 6 — `printf("hello, world");` — and with it, the tradition
is sealed. (Possible roots reach back even further, to
[BCPL](https://en.wikipedia.org/wiki/BCPL).)

**1978 → today — the universal handshake.**
Since K&R, virtually every language tutorial, textbook, and documentation set
opens the same way. "Hello, World" became three things at once: a
**syntax illustration**, a **sanity check** ("is my toolchain installed
correctly?"), and a **rite of passage**. There are now collections documenting
it in hundreds of languages — quite possibly the most translated sentence in
the history of technology.

## 💻 Hello, World in 8 Languages

The 1978 original first, then the classics:

**C** — *the original (K&R, 1978, verbatim)*
```c
main( ) {
        printf("hello, world");
}
```

**Python**
```python
print("hello, world")
```

**JavaScript**
```javascript
console.log("hello, world");
```

**Rust**
```rust
fn main() {
    println!("hello, world");
}
```

**Go**
```go
package main

import "fmt"

func main() {
    fmt.Println("hello, world")
}
```

**Java**
```java
class Hello {
    public static void main(String[] args) {
        System.out.println("hello, world");
    }
}
```

**Bash**
```bash
echo "hello, world"
```

**SQL**
```sql
SELECT 'hello, world';
```

## ✨ Fun Facts

- 🖋️ A handwritten 1978 C version of the program, **signed by Kernighan
  himself**, survives to this day.
- 📉 The original had **no `!`, no capital H, and no newline** — every one of
  those was added by later tradition.
- 🧪 Its serious job is a **sanity check**: if hello-world compiles and runs,
  your toolchain works and you know how to drive it.
- 📚 Wikibooks maintains a collection of hello-world programs in **hundreds**
  of languages — and Wikipedia's editors have formally declared: *no more
  examples shall be added to the article.*\*

## 🔄 The GitHub Flow, As Practiced Here

This repo doesn't just describe the flow — it runs on it. Every change above
arrived the same way:

```

```

No commits land directly on `main`. Even the YOLO merge went through a pull
